5. SUMMARY OF CONSIDERATIONS FOR PHASE 3 (FEATURE ENGINEERING & MODELING)
--------------------------------------------------------------------------------
While the cleaned corpus at data/processed/WELFake_cleaned.csv is structurally
flawless, the following machine learning and feature engineering considerations
must be addressed during Phase 3 before model training:

1. WIRE SERVICE SHORTCUT LEARNING ("REUTERS" ARTIFACT):
   - Over 21,000 real news articles in the cleaned corpus originate from Reuters
     and retain standard journalistic datelines (e.g., "WASHINGTON (Reuters) -",
     "LONDON (Reuters) -").
   - Machine Learning Risk: If text is tokenized without stripping news wire signatures,
     linear classifiers (Logistic Regression, Passive-Aggressive, Naive Bayes) will
     assign massive positive weights to the token "reuters", classifying news as "Real"
     solely based on whether the word "Reuters" appears rather than learning linguistic
     patterns of credibility.
   - Required Phase 3 Fix: Implement regex stripping for recurring publisher datelines
     and wire stamps during NLTK / Scikit-learn text preprocessing.

2. TEXT REPRESENTATION CONCATENATION STRATEGY:
   - In WELFake, articles possess both a 'title' (headline) and 'text' (body).
   - In misinformation detection, headlines often contain sensational clickbait cues
     (excessive capitalization, emotional punctuation) while bodies contain narrative claims.
   - Recommendation for Phase 3: Concatenate 'title' and 'text' into a unified input
     field (e.g. `title + " " + text`) during feature extraction to maximize signal.

3. STRATIFIED CROSS-VALIDATION SPLITTING:
   - The cleaned dataset is well-balanced (55.58% Real vs 44.42% Fake).
   - Phase 3 train/test partitioning must use `StratifiedKFold` or `train_test_split(..., stratify=y)`
     to maintain identical class proportions across training and evaluation splits.

4. TARGET CONVENTION CONSISTENCY:
   - All Phase 3 training scripts should explicitly utilize `label` where:
     * 0 = Fake News
     * 1 = Real News
   - And display predictions using the established `label_name` ('Fake' / 'Real').
